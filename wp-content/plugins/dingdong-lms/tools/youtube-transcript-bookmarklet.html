🐼 dingdong 자막 긁기 v2 (신형 UI 대응)

유튜브 [스크립트 표시] 패널의 자막을 긁어 클립보드 복사합니다. 클래스 이름이 아니라 타임스탬프 패턴으로 찾아 신·구 UI 모두 대응하고, 못 찾으면 진단정보를 자동 복사합니다.

① 설치 — 버튼을 북마크바로 드래그

📋 dingdong 자막 긁기 v2

← 이 버튼을 브라우저 북마크바로 끌어다 놓으세요 (기존 v1 북마크는 삭제)

💡 북마크바가 없으면 Ctrl+Shift+B. 드래그가 안 되면 새 북마크를 만들고 아래 코드를 URL칸에 붙여넣으세요.

② 사용법

  1. 유튜브 영상 열기 → […더보기] 또는 설명란에서 [스크립트 표시] 클릭 (자막 패널 뜸)
  2. 북마크 “📋 dingdong 자막 긁기 v2” 클릭
  3. “OK 자막 N줄 복사됨” 토스트 → dingdong “가사 직접 입력”에 Ctrl+V
혹시 “X 못 찾음 — 진단정보 복사됨” 이 뜨면, 그 상태로 채팅에 Ctrl+V 해서 붙여넣어 주세요. 유튜브 패널의 실제 구조(HTML 일부)가 복사돼 있어서, 그걸 보면 셀렉터를 정확히 맞출 수 있습니다.

참고: 콘솔의 403 / doubleclick CORS / RotateCookies 429 같은 빨간 에러는 유튜브 자체 광고·쿠키 요청이라 북마클릿과 무관합니다. 신경 쓰지 마세요.
